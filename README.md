# Creative Craft

A static storefront for Creative Craft, an Assam-based studio featuring handmade art, handloom, crochet, props, interiors, and culture-inspired keepsakes.

## Features

- Assamese culture-inspired visual design
- Creative Craft logo and local product photography
- Responsive desktop and mobile layout
- Product enquiry cards with WhatsApp redirection
- Instagram profile link
- No public product pricing

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## WhatsApp setup

Update the `whatsappNumber` value near the bottom of `index.html` with the business WhatsApp number, including the country code and excluding the `+` sign.

## Project structure

- `index.html` - complete static webpage
- `creative-craft-logo.jpg` - Creative Craft logo
- `images/` - product photography
